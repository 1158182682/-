# 旅备清单（lvbei_checklist）

离线国外旅行准备清单 App（Flutter）。

## V1 依赖说明

- `sqflite`：本地 SQLite 数据库存储，保存旅行、清单、美食、注意事项、应急卡等离线数据。
- `path`：用于拼接数据库文件路径，确保在不同平台上路径处理一致。
- `provider`：轻量状态管理方案，用于页面与数据层状态同步（如清单勾选状态、列表刷新）。
- `intl`：日期/时间格式化与本地化展示（如出发日、返回日格式）。
- `uuid`：生成本地唯一 ID，便于离线数据创建时先分配标识。

## 暂不引入的依赖（按需求）

- 云服务相关 SDK
- 地图相关 SDK
- 登录鉴权相关 SDK
- 网络请求相关 SDK
